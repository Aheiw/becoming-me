# 成我 · Becoming Me

**一本关于我如何成为我的书。**

我来讲述，AI 帮我整理，解释权始终在我。

成我是一个在本机运行的中文个人历史与百科工具。你可以在同一个长期对话里讲述经历，或导入日记；需要保留的内容先整理成建议，由你确认后再归档。它不追求记录每天的琐事，而是让重要的经历和关于自己的判断有来龙去脉。

## 现在可以用它做什么

- **长期对话与资料库**：普通聊聊、记事件、聊梦境共享聊天界面，不必新开访谈。AI 可以按需查事件、百科和日记；命中的原话可以回到原件核对。
- **写日记**：直接在网页写，选择只存原文或保存并立即分析；AI 发现先到收件箱。
- **日记资料库**：统一导入、保存、分析日记，按日历或保存批次回看原文，颜色越深表示当天写得越多。也能一键分析所有待分析批次，不重复处理已完成的批次。
- **批量日记**：可选多个文件或整个文件夹，不设固定篇数上限。先保留原件，再按长度分段分析和跨篇归并；分析中断后可以从资料库继续。结果先到收件箱，不自动写入百科。
- **事件簿与人生书**：按时间或章节回看经历，记录经过、结果、原话和后来的回访。
- **个人百科**：把关于自己的理解整理成主题条目，支持修改、查看修订和恢复旧版。
- **梦境簿**：单独保存梦的原话和联想，不把梦当成现实事件或性格依据。
- **人物与环境**：记录人物、地方和生活条件。可从事件或档案任一侧修改关联，再双向跳转；一条人物或环境关系也能附上相关事件。日记分析会建议新建、补充或关联档案；核对引文后，可以编辑、确认或忽略，不会自动建档。
- **设置**：填写 API 端点、密钥和模型名，或检测可用模型并选择。可一键备份、恢复、清除全部个人记录，也可单独导出人生书和梦境簿。

## 在 Windows 本地运行

需要 Node.js 22、npm 和 PowerShell。以下命令从仓库根目录运行：

```powershell
npx --yes --package pnpm@10 pnpm install --frozen-lockfile
npm ci --prefix local-runtime
npx --yes --package pnpm@10 pnpm --filter web build
.\start-local.cmd
```

启动后打开 `http://127.0.0.1:4527/`，进入「设置」，填写 OpenAI 兼容 API 的基础地址、密钥和模型名。可以先点「检测模型」，也可以直接手填模型 ID。保存后下一次调用生效，无需重启。密钥使用 Windows 账户加密；旧的本机配置仍可作为首次启动时的默认配置。

## 数据与隐私

数据库和本机凭据放在 `data/`，不会随代码提交。使用聊天、分析等功能时，该功能所需的上下文会发送到你配置的模型 API；**在本机运行不代表完全离线**。向量检索使用本机 Ollama 的 `bge-m3:latest`；不可用时退回关键词检索。关闭聊天中的日记检索，不会从已有聊天或已核对条目中删除引文。请自行保管资料库备份，不要把真实日记、聊天、人物档案、导出文件或密钥放进 Git。

**手机连接：** 在电脑「设置 → 手机连接」选择连接路由器的局域网地址，点「开启手机连接」。手机连同一个路由器，扫码或输入网址，再填电脑显示的 8 位配对码。配对码 5 分钟内只能成功使用一次，输错 5 次后请重新生成。授权保存在电脑，使用同一浏览器、同一地址时，服务重启或暂停后重新开启也不用重新配对。可在电脑撤销单台设备；清理浏览器数据、换浏览器或换地址后需要重新配对。手机操作的是同一份资料，模型、备份和设备管理仅在电脑端开放。默认不开手机访问；局域网流量是 HTTP，请只在信任的网络使用，不要将端口映射到公网。电脑需保持成我运行。访客 Wi-Fi 或防火墙可能阻止设备互访。

**备份和清除：**「设置 → 一键备份」将记录保存到项目的 `data/backups/`。可在相同页面选择备份恢复（替换现有记录，恢复前另存备份）。删除所有记录需要等待 5 秒并再次确认；自动备份成功后才清除，包括长期对话和旧访谈。不删除外部原文件或模型配置。备份文件为未加密的 JSON，不包含 API 密钥；可移到安全位置，需要恢复时放回该文件夹。
